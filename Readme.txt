Instsructions to open this portfolio locally.

First and foremost, you will need a xampp installed on your device. 
If you already have it installed, strictly follow the steps below.

STEP 1. Open the XAMPP control panel. You can search it on your windows search bar if you don't know the current location of you application.

STEP 2. Start Apache and MySQL, if you encounter the problem where you can't start the MySQL do these simple and quick troubleshooting
    * press windows + r/ command + required and type "services.msc"
    * find MYSQL80, right click that and stop it.
    * try starting the MYSQL on your XAMPP and it should work now

STEP 3. We need to put the project folder(Alfarero_Portfolio) inside the xampp/htdocs directory. Follow these steps to navigate through it:
    * Open your File Explorer 
    * Go to your C-drive: (C:)
    * find the folder "xampp", open it
    * find the folder "htdocs", open it
    * Copy the project folder(Alfarero_Portfolio) and paste it inside the "htdocs"

STEP 4. You can now go to your web browser(google, operaGX, microsoft edge) and type "localhost/yourProjectName". 
        In this case type localhost/Alfarero_Portfolio.
Step 5. You can now view my portfolio. Please hire me. Enjoy.
